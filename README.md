# Becoming Her Journey

BUILD: BECOMING HER — DIGITAL JOURNAL

I have uploaded two authoritative source files for this project:

SOURCE FILE 1:

A clean redesigned Becoming Her cover image, approximately 1500–2000 px wide.

SOURCE FILE 2:

The complete Becoming Her interior/manuscript PDF.

IMPORTANT SOURCE RULE:

The COVER IMAGE is the PRIMARY VISUAL DESIGN REFERENCE.

The INTERIOR PDF is the AUTHORITATIVE CONTENT SOURCE.

Do not invent, rewrite, modernize, summarize, or alter the theological content of the manuscript.

The goal is NOT to turn the PDF into a website.

The goal is to transform the existing print journal into a premium, private, mobile-first DIGITAL JOURNEY.

14. PRIVATE DATA

==================================================

Journal responses are PRIVATE.

A user must only be able to access her own responses.

If using Supabase:

• Supabase Auth

• PostgreSQL

• Row Level Security

Every journal response must be associated with the authenticated user.

Implement database-level protection.

Do NOT expose private journal responses publicly.

Do NOT make private reflections indexable by search engines.
